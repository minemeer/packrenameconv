Minecraft Rename-Item Pack Generator

Creates resource packs where renamed items (anvil) receive a new 2D texture or 3D model.
Supports Minecraft 1.21.4+ to 26.3 (item definitions in assets/.../items/). Free & fully in-browser.

What does this tool do? With the Minecraft Rename-Item Pack Generator you create resource packs in which items get a custom texture or 3D model after being renamed on an anvil – no mods, pure vanilla mechanics (Custom Name + item definitions from 1.21.4/1.21.5).

Features: 2D PNG textures, 3D models from ZIP (e.g. Blockbench), selectable pack format (46–97), import existing packs for further editing, fully client-side – no server uploads.
